Our assurance tool told users to build an emission factor register: factor, source, vintage, applied-to. We did not have one ourselves.

So we built it, and audited our own code against it. Four things we found:

— One factor existed in three places — the arithmetic, the label shown to the user, and the CSV export. Changing one did not change the others, so an audit trail could state a factor that was not the one applied.

— R-22 computed at 1760 while the selector beside it displayed 1810, and the trail described the set as AR6. Three vintages in one control. The set is AR4; the label was right and the engine was wrong.

— A project finance intensity sat roughly 4,000x below the corporate lending default in the same units. Not plausible for the asset class. No sourced replacement could be established, so the default was withdrawn rather than replaced with a better-looking guess.

— A table of factors nobody used disagreed with the values users actually got: India grid 0.82 against 0.716, waste 0.58 against 0.467.

The register is now public, and it publishes what is weak: 8 of 27 factors are low confidence, and 4 have no establishable source at all. Every calculated number opens to show the factor applied, its vintage, its source, and our own caveat about it.

None of this is unusual in emissions software. It is unusual to publish it.
