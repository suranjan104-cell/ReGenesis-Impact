# ReGenesis Impact — Path to #1

Goal: the most-used AI-powered ESG/climate platform for SG · AU · IN.
"#1" decomposes into three measurable races: **rank first** for the
regulatory searches buyers actually make, **convert best** once they land,
and **retain deepest** because the tools genuinely do the work. Every stage
below moves one of those needles and is verifiable from the repo.

## Stage 1 — ACQUISITION (implemented in this PR)

The site is a single-page app: search engines effectively see one URL.
Buyers search long-tail regulatory questions ("AASB S2 Group 2 deadline",
"BRSR Core assurance requirements"). We win those with **programmatic guide
pages** generated from the same verified knowledge base the AI uses:

- `guides/*.html` — one static, crawlable page per framework × market,
  generated by `seo/build-guides.mjs` from `seo/guides-data.mjs`
- Each page: unique intro, verified key facts (sourced), FAQ with
  `FAQPage` JSON-LD, deadline callout, and CTAs into the relevant tool
- `sitemap.xml` regenerated to list every guide; footer links them so
  crawlers and users both find them
- Zero duplication risk: guides cite the KB entries; updating the KB and
  re-running the generator refreshes the guides

KPIs: indexed pages (Search Console), impressions for framework keywords,
guide → tool click-through (already tracked as `tool_open` events).
