Our assurance tool told users to build a register — factor, source, vintage, applied-to — and to treat a factor older than three years as a finding. We did not have one ourselves. So we built it, ran our own code against it, and published the result including the parts that do not flatter us.

Four things we found in our own code

One factor lived in three places. The arithmetic, the label shown to the user, and the CSV export each held their own copy. Changing one did not change the others — so an audit trail could state a factor that was not the one applied.
R-22 carried three vintages in one control. The engine computed with 1760, the selector beside it displayed 1810, and the audit trail described the set as AR6. The set is AR4, recoverable by arithmetic from our own blend values: solving R-410A against our R-32 implies R-125 = 3501, which then reproduces our R-407C and R-404A. The label was right; the engine was wrong.
A project finance intensity sat roughly 4,000× too low. 0.035 tCO2e per USD mn against 150 for corporate lending in the same units. Not plausible for the asset class. No sourced replacement could be established, so the default was withdrawn rather than replaced with a better-looking guess.
A table nobody used disagreed with what users got. India grid 0.82 against the 0.716 actually applied; waste 0.58 against 0.467. Dead configuration that read as authoritative.

What the register does now

Every factor carries its value, unit, basis, region, source, vintage, confidence and the calculation lines it feeds. Every computed number opens to show the factor applied and its provenance. Every editable factor warns you at the point of entry if it is unsourced, so the decision to override is made with that in front of you rather than discovered later.

Emission lines are scored 1–5 for data quality and rolled up, emissions-weighted, to an inventory score. That scheme is ours, not a standard — PCAF specifies 1–5 for financed emissions and no equivalent scale exists for general activity data, so it mirrors the logic without claiming to be it.

None of this is unusual in emissions software. It is unusual to publish it.

The four unsourced factors are still unsourced. They are named in the register, ranked in the gap list of any inventory that uses them, and printed in the assurance pack a reviewer reads. That is the point: a number you cannot defend should be visible before someone else finds it.
